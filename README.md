# Battleship Repo

## Quick Guide

This is my repo for a battleship game, programmed with **C++**. The game is one player vs a bot, with the bot having a _targeting_ and _hunting_ mode of operation, determining its current moves based on a positive or negative response to its previous moves.

The project operates with a main file where the program runs, and a variety of header files where the logic of the game, the board, the player, and the bot are determined.
